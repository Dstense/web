# Abad Web Studio — GitHub Pages

A premium, dependency-free business website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — complete page
- `style.css` — responsive visual system
- `script.js` — mobile nav, motion, reveal animations and hero interaction
- `favicon.svg` — site icon

## Publish on GitHub Pages
1. Create a new GitHub repository.
2. Upload all files from this folder to the root of the repository.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
